Fetched from the 3DEP ImageServer `exportImage` endpoint, which mosaics the best
available 3DEP source (here the 1 m lidar DEM above) for the requested pixel size:

```
https://elevation.nationalmap.gov/arcgis/rest/services/3DEPElevation/ImageServer/exportImage?bbox=482323.256%2C4608063.267%2C482523.256%2C4608263.267&bboxSR=26916&imageSR=26916&size=257%2C257&format=tiff&pixelType=F32&interpolation=RSP_BilinearInterpolation&renderingRule=%7B%22rasterFunction%22%3A+%22None%22%7D&f=image
```

The heightmap `dem/indiana_dunes_dem.tif` is float32 metres with the minimum subtracted, so z = 0
in Gazebo is 176.86 m NAVD88. Gazebo Fortress loads `.tif` heightmaps through GDAL as a DEM.
The model sets `<size>` explicitly (x, y = patch size, z = relief), so the result is right
whether Gazebo scales by size or uses the raw heights. The textures are procedurally
generated by the script (no imagery).

3D Elevation Program.
